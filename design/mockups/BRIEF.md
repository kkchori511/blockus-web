# 블로커스 웹 게임 — 콘셉트 목업 요청 (1단계)

이미지 생성 도구로 아래 목업 3장을 만들어 이 폴더(`design/mockups/`)에 PNG로 저장해 주세요.
다른 파일은 만들거나 수정하지 마세요. 끝나면 저장한 파일 경로와 각 이미지에 대한 짧은 자기 검토(브리프와 다른 점)를 알려 주세요.

## 공통 디자인 방향
- 로컬 대전용 블로커스(Blokus) 보드게임 웹앱. PC 모니터·태블릿 가로 화면.
- 핵심 질감: **투명한 컬러 플라스틱 조각**. 실제 블로커스 조각처럼 반투명하고, 위쪽 모서리에 광택 하이라이트, 칸마다 살짝 볼록한 베벨, 보드 위에 색이 비치는 그림자.
- 색 4개: 파랑(blue), 노랑(yellow), 빨강(red), 초록(green). 선명하지만 촌스럽지 않게.
- 전체 톤: 밝고 깔끔한 모던 UI, 부드러운 라운드 모서리. 보드는 밝은 회색/흰색 계열의 매트한 플라스틱 판, 20×20 격자 홈.
- 텍스트는 최소화. 닉네임 자리는 짧은 영문 placeholder(예: "Player 1")로.

## 이미지 1 — `game-16x9.png` (1920×1080, 16:9)
4인 클래식 게임 중반, **파랑 차례** 화면.
- 가운데: 정사각형 20×20 보드가 화면 높이를 거의 다 채움. 네 색 조각이 각자 모서리(파랑 좌상, 노랑 우상, 빨강 우하, 초록 좌하)에서 시작해 중앙 쪽으로 뻗어 나간 상태(조각은 같은 색끼리 꼭짓점으로만 이어짐, 같은 색끼리 변이 맞닿지 않음).
- 좌우 여백: 각각 위아래 두 영역으로 나뉘어 총 4개 플레이어 영역. 영역 배경은 해당 플레이어 색의 연한 톤.
  - 좌상 파랑, 우상 노랑, 우하 빨강, 좌하 초록.
  - 각 영역: 닉네임, 점수(숫자), 작은 타이머 아이콘 버튼, 되돌리기(↶) 아이콘 버튼, 나머지 공간에 남은 조각들을 작게 나열.
- **현재 차례인 파랑 영역은 왼쪽 세로 전체로 확장**되고, 초록 영역은 왼쪽 아래에 얇은 띠로 접힘.
  - 확장된 파랑 영역 가운데에 **원형 캐러셀**: 가운데 조각이 크게, 좌우 조각이 작고 약간 잘려 보이며 뒤로 물러난 원근감(총 3개 보임). 아래에 회전·뒤집기 버튼, 좌우 넘김 화살표.
  - 보드 위에는 파랑 조각 하나가 드래그 중인 반투명 미리보기(초록 윤곽 = 놓을 수 있음)와 "확정" 버튼.

## 이미지 2 — `game-4x3.png` (1600×1200, 4:3, 태블릿)
이미지 1과 같은 장면을 4:3 화면에 맞춘 버전. 좌우 영역이 너무 좁아지지 않도록 **보드를 줄여** 좌우 영역의 최소 폭을 확보한 레이아웃.

## 이미지 3 — `piece-closeup.png` (1600×1200)
질감 레퍼런스. 보드 일부를 가까이서 본 장면: 네 색 투명 플라스틱 조각 몇 개가 격자 홈 위에 놓여 있고, 빛 반사·투과·색 그림자가 잘 보이게. 웹에서 SVG/CSS로 재현할 목표 질감.
